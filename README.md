# cyberdojang
This project aims to utilise artificial intelligence (AI) in gamified cybersecurity training to prevent human errors in data security. The system will customise training content for specific users using AI-driven adaptive learning, behavioural analysis, and interactive simulations to enhance engagement and retention. In particular, the goal is to develop and test a gamification platform powered by AI that adapts to the user’s learning needs, offering a more effective and practical approach to cybersecurity education. This research is intended to address the gaps in traditional training methods by increasing the effectiveness and accessibility of cybersecurity awareness programmes.
