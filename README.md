## Overview

**cybrNinja** is a powerful developer tool designed to enhance cybersecurity awareness through interactive quizzes and real-time engagement.

**Why cybrNinja?**

This project empowers developers to create engaging learning experiences while ensuring robust security and performance. The core features include:

- **🎯 Dynamic Quiz Generation:** Leverages OpenAI's API to create unique phishing-related quiz questions, enhancing user engagement.
- **🏆 Real-time Leaderboard Updates:** Implements threading to keep the application responsive while updating user rankings daily.
- **🔒 User Authentication and Security:** Integrates JWT for secure access to protected routes, ensuring data integrity.
- **⚙️ Centralized Configuration Management:** Streamlines access to essential services like MongoDB and Auth0, enhancing maintainability.
- **📱 Responsive Frontend Design:** Built with Next.js and Tailwind CSS, providing a visually appealing and user-friendly interface.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** TypeScript
- **Package Manager:** Pip, Npm

### Installation

Build cybrNinja from the source and intsall dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/dammyvc/cybrNinja
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd cybrNinja
    ```

3. **Install the dependencies:**

**Using [pip](https://pypi.org/project/pip/):**

```sh
❯ pip install -r backend/requirements.txt
```
**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### Usage

Run the project with:

**Using [pip](https://pypi.org/project/pip/):**

```sh
python {entrypoint}
```
**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### Testing

Cybrninja uses the {__test_framework__} test framework. Run the test suite with:

**Using [pip](https://pypi.org/project/pip/):**

```sh
pytest
```
**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
